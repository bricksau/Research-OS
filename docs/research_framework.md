# Research-OS: 通用实证与社科研究操作系统架构

## 1. 设计哲学 (Philosophy)
Research-OS 旨在解决社科与经济学实证研究中长期的“散乱痛点”：
- **数据与论文断联**：表格数字手工抄写，改了代码忘了改论文；
- **AI 幻觉滋生**：直接让 AI 写论文导致虚假文献、空洞修辞、伪造数据；
- **多端协作混乱**：云盘同步损坏 Git 仓库，不同电脑版本打架。

## 2. 五层分层架构 (5-Layer Architecture)

┌──────────────────────────────────────────────────────────┐

                             │ (数字严格绑定)

                             │ (标准面板输入)
