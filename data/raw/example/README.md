# Example data (synthetic)

`example_trade.csv` is invented, so that the checks have something to run on in a fresh copy of the template.
`src/analysis/example_table.py` turns it into `output/tables/example_trade_balance.csv`; one sentence in
`papers/manuscript/Paper_Master_Template.md` (section 4) quotes the result; `config/expected_numbers.yaml` ties the two
together. Delete all four example pieces when your own data arrive.
